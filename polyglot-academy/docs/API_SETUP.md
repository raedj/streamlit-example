# إعداد مفاتيح API والخدمات الاختيارية (API setup)

كل ما في التطبيق يعمل دون اتصال ودون مفاتيح: الدروس، المراجعة، القصص المدمجة، المدرّب
النصّي المبرمَج، النقاط والمهام اليومية. المفاتيح التالية اختيارية، وتضيفها من داخل التطبيق
(لا تُكتب في الكود أبدًا، وتُخزَّن مشفّرة على الجهاز، ولا تدخل في ملفات التصدير).

> Everything works offline without keys. The services below are optional; keys are entered in the
> app at runtime, stored encrypted on the device and never exported.

## 1. تفعيل الذكاء الاصطناعي السحابي (مطلوب لكل ما يلي)
الإعدادات ← الخصوصية ← فعّل «السماح بالذكاء الاصطناعي السحابي» ووافق على الإفصاح.
للتقييم الصوتي والمكالمات المباشرة فعّل أيضًا فئة «التسجيلات الصوتية» (مطفأة افتراضيًا).

## 2. مزوّد المحادثة الذكية (المدرّب، القصص، تصحيح الكتابة، قراءة الصور)
الإعدادات ← مزوّدو الذكاء الاصطناعي ← اختر مزوّدًا وأدخل المفتاح ← «اختبار الاتصال».

| المزوّد | من أين المفتاح | ملاحظة |
|---|---|---|
| OpenAI | platform.openai.com ← API keys | المفتاح نفسه يُستخدم للمكالمات الصوتية المباشرة |
| Google Gemini | aistudio.google.com ← Get API key | |
| Anthropic Claude | console.anthropic.com ← API Keys | |
| Azure OpenAI | بوابة Azure ← مورد Azure OpenAI ← Keys and Endpoint + اسم الـ deployment | |
| DeepSeek | platform.deepseek.com | |
| خادم محلي (Ollama / LM Studio) | لا يحتاج مفتاحًا؛ أدخل العنوان مثل http://localhost:11434/v1 | على أندرويد: من المحاكي استخدم 10.0.2.2 |

اشتراكات المستهلكين (ChatGPT Plus، Gemini Advanced، Copilot) ليست مفاتيح API.

## 3. تقييم النطق المفصّل (Azure AI Speech)
1. في بوابة Azure أنشئ موردًا من نوع **Speech** (توجد فئة مجانية F0).
2. انسخ **Key 1** و**Region** (مثل `westeurope` أو `uaenorth`).
3. في التطبيق: الإعدادات ← خدمات الصوت ← أدخل المنطقة والمفتاح ← حفظ ← «اختبر المفتاح».
4. جرّبه من: تدرّب ← النطق ← «تقييم مفصّل» ← سجّل وقيّم.

## 4. المكالمات الصوتية المباشرة (OpenAI Realtime) — تجريبية
- تستخدم مفتاح OpenAI من الخطوة 2.
- الإعدادات ← خدمات الصوت: النموذج الافتراضي `gpt-realtime` (عدّله إن تغيّر اسم النموذج لدى OpenAI) واختر صوت المدرّب.
- ابدأ من: تبويب المعلّمون ← «مكالمة صوتية مباشرة (تجريبية)». يمكنك مقاطعة المدرّب بالكلام، وتظهر تصحيحات جملك في النص.
- على الحاسوب استخدم سماعات رأس (لا يوجد إلغاء صدى).

## 5. المزامنة بين الأجهزة (WebDAV مشفّر)
1. تحتاج مساحة WebDAV خاصة بك عبر HTTPS: Nextcloud أو ownCloud أو مزوّد استضافة يدعم WebDAV.
   - Nextcloud: العنوان عادةً `https://SERVER/remote.php/dav/files/USERNAME`، ويُفضّل إنشاء «كلمة مرور تطبيق» من إعدادات الأمان.
2. في التطبيق: الإعدادات ← بياناتك ← «المزامنة بين الأجهزة» ← العنوان واسم المستخدم وكلمة المرور
   و**عبارة مرور التشفير** (10 أحرف على الأقل، نفسها على كل جهاز) ← حفظ ← «زامن الآن».
3. على الجهاز الثاني أدخل البيانات نفسها واضغط «زامن الآن»؛ الجهاز الجديد يأخذ نسخة الخادم.
4. إذا تغيّر الجهازان معًا يسألك التطبيق: الاحتفاظ بهذا الجهاز أم استخدام نسخة الخادم.

> إن فقدت عبارة المرور فلا يمكن لأحد قراءة النسخة المخزّنة، وهذا مقصود.

## 6. ما الذي يُرسل وإلى أين
| الميزة | ما يُرسل | إلى |
|---|---|---|
| المدرّب والمحادثة النصية | نص المحادثة | مزوّدك المختار |
| القصص بالذكاء الاصطناعي | الموضوع والمستوى وبضع كلمات تعرفها | مزوّدك المختار |
| تقييم النطق | تسجيل واحد (≤ 20 ثانية) والجملة المرجعية | مورد Azure الخاص بك |
| المكالمة المباشرة | الصوت أثناء المكالمة، ونص جملك للتصحيح | OpenAI |
| المزامنة | ملف واحد مشفّر بالكامل | خادم WebDAV الخاص بك |

## 7. حالة التحقق
هذه الخدمات مختبرة بخوادم وهمية (mock) فقط في بيئة التطوير، ولم تُجرَّب بمفاتيح حقيقية بعد
(docs/KNOWN_ISSUES.md: K-17، K-18، K-19). جرّبها على جهازك بعد بناء التطبيق، وأرسل أي خطأ يظهر.
