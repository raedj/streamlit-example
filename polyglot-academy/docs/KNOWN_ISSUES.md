# Known Issues and Limitations

| ID | Severity | Issue | Impact / workaround |
|---|---|---|---|
| K-01 | Medium (process) | The debug APK builds (AGP 8.7.3, Windows, JDK 17) and runs on an Android 15 emulator (2026-10-25). Release build, R8 shrinking and signing are not verified | Build `bundleRelease` with a keystore and test the shrunk build |
| K-02 | Medium (process) | UI partly executed on an Android 15 emulator (Arabic interface: onboarding, home, one lesson end to end, tabs, offline tutor). Not yet checked: English interface in depth, every screen, layout, clipping, RTL mirroring and TalkBack order unverified. `:ui:desktopTest` cannot even resolve its runtime classpath here (androidx.collection/annotation come from Google Maven) | Run `:ui:desktopTest` where Google Maven is reachable, capture screenshots, test on devices |
| K-03 | Medium | Default AI model ids may be outdated by the time of release | Learner can edit the model; verify against vendor catalogues |
| K-04 | Medium | PDFs with real text are extracted on device (pure Kotlin). Photos and scanned PDFs can be read with a vision AI provider (OpenAI, Gemini, Claude) on explicit request; this sends the images to that provider and needs cloud AI allowed. Scanned PDFs need page rendering, which exists on Android (PdfRenderer) but not in the desktop harness. No on-device OCR; no audio/video transcription; encrypted PDFs and LZW content unsupported. Arabic/Hebrew lines are ordered by glyph position; multi-column layouts can come out in the wrong order | Paste text or import .txt/.srt/.vtt for unsupported files |
| K-05 | Medium | No on-device LLM runtime; on-device provider is always unavailable | Use a local OpenAI-compatible server or a cloud provider |
| K-06 | Low | Restore implemented (Settings → Your data); the restored reminder is re-scheduled (asking for notification permission if it is on). Version 1 exports restore profile, settings, lessons, reviews, vocabulary and mistakes only; reduced v1 phrase/assessment/note records are skipped and counted | Fixed 2026-10-25 (partial for v1 files) |
| K-07 | Low | Built-in content: about 130–140 words and 17–22 lessons per language, including a daily-life and travel pack in every language (essential phrases, emergencies, restaurant, hotel, transport, sightseeing; 48 phrases and 3 role-plays each). Turkish, Urdu and Malay (added 2026-10-25): about 115–120 words and phrases, 19 lessons, 10 grammar topics, 6 role-plays, 3 graded stories and a 12-item placement bank each, A1–B2. Every language reaches B1 (B2 grammar in EN/ES/FR/TR/UR/MS); no C1 general lessons (C1 is covered by speaking missions with an AI tutor) | Content packs can be added without engine changes |
| K-08 | Low | Pronunciation feedback is recognizer text similarity, not phonetic/tone analysis (disclosed in UI) | — |
| K-09 | Low | Character writing practice exists (trace/from memory, shape-overlap check against the font glyph, stroke counts and components for 98 course characters). Stroke order and direction are not checked, and there is no animated stroke-order demo (no licence-compatible stroke data bundled); traditional characters have no breakdowns | Partly addressed 2026-10-25 |
| K-10 | Low | Avatars are original animated 2D vector portraits (blinking, breathing, nods, five expressions). Mouth shapes follow the spelling of the word the TTS engine reports, or the loudness of the voice in live calls (measured when audio arrives, so it can run slightly ahead of playback); not phoneme-accurate lip-sync, and there are no 3D or video avatars (would need licensed assets) | — |
| K-11 | Low | Reminder notification text is fixed (no per-language variety beyond EN/AR) | — |
| K-12 | Low | Bar and line charts support tap-to-inspect (tooltip with label and value); there is no pinch-zoom | Values are labelled and described for screen readers |
| K-13 | Low | Business and finance tracks exist in all eight languages; credit-risk and legal tracks are English only | — |
| K-14 | Low | Compose Multiplatform 1.7.3 / Kotlin 2.1.21 chosen for offline resolution; newer versions exist | Upgrade once Google Maven is reachable |
| K-15 | Medium | Speaking path (30 missions, A1–C1): missions without a built-in role-play need an AI tutor; pass criteria (turns, median turn length, tutor confirmation) are practice targets, not a certified level. Speaking rate uses recognizer timing and is approximate; Mandarin word counts are estimated from characters | — |
| K-16 | Low | The AI coach protocol (track choice, warm-up, Socratic hints, error log re-tests, frustration handling) depends on the AI model following instructions; the app supplies the memory and records errors itself, but cannot enforce, for example, that every reply ends with a question. Without an AI provider only scripted conversations are available. Exam tasks are AI-written practice, not official material | Errors are still logged and shown even when the model ignores a rule |
| K-17 | Medium | Detailed pronunciation scoring uses Azure AI Speech with the learner's own key; tested only against recorded/mock responses, never the live service. At most 20 s per recording; locale list may change; scores are the service's automatic estimate | Verify with a real key before release |
| K-18 | Medium | Live voice calls (beta) use OpenAI Realtime over WebSocket; tested with a fake socket, microphone and speaker only. The event format follows the documented API (older beta names also accepted) but has not been run live. Desktop capture has no echo cancellation (use headphones). Calls cost more than text chat | Verify with a real key on a device |
| K-19 | Low | Sync is whole-state through one encrypted file on the learner's WebDAV server: no record-by-record merge (on conflict the learner keeps one side), no automatic background sync, HTTPS only. A lost passphrase makes the server copy unreadable by design | Merge per record is a possible later improvement |
| K-20 | Low | XP, quests, levels and streak freezes are computed on the device; there are no leaderboards, friends or leagues (these need a server and accounts, not part of this app) | — |
| K-21 | Low | 24 built-in graded stories (3 per language). AI-written stories are validated for structure, not for factual or linguistic accuracy; the reader says they may contain mistakes | — |
| K-23 | Medium | Turkish, Urdu and Malay content was written by AI and has not been reviewed by native speakers (see docs/CONTENT_SOURCES.md). Detailed pronunciation scoring reports "not available for this language" for them because no Azure locale has been confirmed. Urdu is shown in the device's Naskh-style font, not Nastaliq. "Malay" means Bahasa Melayu as used in Malaysia | Native-speaker review before release; verify Azure locales and add them if supported |
| K-24 | Low | Listening exercises are shown even when the device has no TTS voice for the language; the learner sees a clear message but must guess, and the guess counts toward the score | Skip or mark as ungraded when no voice is available |
| K-25 | Low | Lesson length differs between the home card (planner estimate) and the lesson page (lesson minutes), e.g. 8 vs 6 minutes | Use one source for both |
| K-26 | Low | A resumed lesson is scored only on the exercises done after resuming, so the "lesson without mistakes" achievement can be earned despite earlier mistakes | Persist first-try results with the resume point |
| K-22 | Info | Not implemented: paid subscriptions, live human tutors, accounts/server backend, iOS build (Kotlin Multiplatform makes iOS possible but needs macOS/Xcode) | Product decisions outside this codebase |
